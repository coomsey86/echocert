# EchoCert Public Roadmap

This roadmap shows the public product direction without exposing private commercial implementation details.

---

## Phase 1 — Public prototype

Status: **Complete / demonstrated**

- Receipt generation
- SHA-256 verification
- Diff reports
- HTML audit reports
- Demo scripts
- Public documentation
- Public/private boundary guidance

---

## Phase 2 — Professional evidence packs

Status: **Next**

- PDF report generation
- Evidence pack export
- Clearer report templates
- Case reference fields
- Investigator / reviewer fields
- Better Windows demo flow
- Example evidence pack using only safe demo data

---

## Phase 3 — Desktop workflow

Status: **Planned**

- Drag-and-drop interface
- Simple case dashboard
- Receipt viewer
- Verify button for non-technical users
- Client-friendly export options
- Local archive folder structure

---

## Phase 4 — Business edition

Status: **Planned**

- Organisation-level templates
- Team review workflow
- Branded evidence reports
- Internal governance records
- Multi-user review process
- Audit-ready exports

---

## Phase 5 — Enterprise / integration layer

Status: **Future**

- API access
- Immutable receipt chains
- Digital signature support
- Compliance exports
- Multi-model support
- Integration with AI governance workflows

---

## What will stay private

The public roadmap will not expose:

- Client data
- Private commercial logic
- Production-only workflows
- Proprietary scoring or review logic
- Private signing infrastructure
- Sensitive personal, legal, health or financial data

See [`PRIVATE_PUBLIC_BOUNDARY.md`](PRIVATE_PUBLIC_BOUNDARY.md).

---

## Goal

Become a practical AI evidence and audit platform that organisations can understand in minutes, test safely and deploy with confidence.
