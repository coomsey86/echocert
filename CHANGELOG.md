# Changelog

All notable public changes to EchoCert are recorded here.

This changelog covers the public repository and public-safe product positioning only. Private commercial builds may have separate release notes.

---

## 2026-07-27 — Product positioning and pilot-readiness update

### Changed

- Repositioned EchoCert from a primarily AI prompt/output audit tool to a broader **local-first digital evidence integrity system**.
- Clarified that AI prompt/output auditing remains a supported use case rather than the complete product identity.
- Updated the public description of **EchoCert Elite v0.9.4** as a private controlled-pilot-ready Windows desktop build.
- Added public-safe status for the private Android companion and its physically tested photo/video capture → SHA-256 receipt → re-verification workflow.
- Updated buyer positioning toward inspection, field services, legal/dispute preparation, compliance, audit, property/condition and specialist investigation workflows.
- Reworked the controlled pilot offer around real-user validation, usability and willingness to pay rather than feature demonstrations.
- Updated the roadmap to reflect completed desktop milestones and demonstrated Android core workflows.
- Strengthened claims boundaries around SHA-256, local timestamps, truth, authorship, chain of custody, court status and forensic accreditation.
- Clarified that the public repository is **source-available under BSL 1.1** rather than simply describing it as unrestricted open source.
- Updated the public/private boundary to protect client evidence, credentials, protected implementation details and production workflows.

### Current public-safe product status

- **Public GitHub repository:** working demonstration of receipt, hashing, verification, diff and reporting foundations.
- **EchoCert Elite desktop:** private v0.9.4 controlled-pilot-ready build with file hashing, receipts, reports, evidence packs and verification workflows demonstrated.
- **EchoCert Mobile:** private Android development companion with physical-device photo/video capture, receipt creation and re-verification demonstrated.

### Current priority

- Pilot validation
- UX simplification
- Security hardening
- Failure/edge-case testing
- Desktop/mobile interoperability
- Early paid conversion evidence
