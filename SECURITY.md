# Security Policy

## Public repository safety

This repository is a public demonstration of EchoCert. Do not upload sensitive material to this repository.

Do not commit:

- Client data
- Legal evidence
- Personal records
- Health, family or financial information
- Passwords, tokens, API keys, certificates or recovery phrases
- Private signing keys or salts
- Production-only workflows
- Proprietary commercial scoring, ranking or review logic

## Reporting a security issue

If you find a security issue, please do not open a public GitHub issue containing exploit details or sensitive information.

Contact: paulmccombs@pm.me

Include:

- A short description of the issue
- The affected file or workflow
- Steps to reproduce, if safe to share
- Whether any secret, token, client data or private evidence may be exposed

## Scope

This policy covers the public EchoCert repository only. Private commercial builds, client deployments and internal workflows are handled separately.

## Principle

The public repository should demonstrate value without exposing private data, private workflows or production-only implementation details.
