# Contributing

Thanks for your interest in EchoCert.

This public repository is intended for demonstration, documentation, evaluation and safe public discussion.

---

## Public contribution rules

Please do not submit:

- Client data
- Real legal evidence
- Personal records
- Health, family or financial information
- Passwords, tokens, API keys, certificates or recovery phrases
- Private signing keys or salts
- Production-only workflows
- Proprietary commercial scoring, ranking or review logic
- Private framework files or private continuity notes

---

## Good public contributions

Useful public contributions may include:

- Documentation improvements
- Typo fixes
- Safe demo examples
- Test improvements using dummy data only
- Bug reports that do not expose sensitive data
- Suggestions for clearer public messaging

---

## Security issues

Please do not open a public issue containing exploit details or sensitive information.

See [`SECURITY.md`](SECURITY.md) for reporting guidance.

---

## Licensing

By contributing, you agree that public contributions may be included in the repository under the existing project licence.

Commercial or production use of EchoCert requires a separate commercial licence. See [`LICENSE`](LICENSE) and [`LICENSING.md`](LICENSING.md).
