# EchoCert Licensing Overview

EchoCert's public repository is currently licensed under the **Business Source License 1.1 (BSL 1.1)**.

The public code is **source-available**. It should not be described simply as unrestricted open-source software.

The [`LICENSE`](LICENSE) file is the controlling licence text. This page is a plain-English overview only and is not legal advice.

---

## Public evaluation

Subject to the current licence terms, users may generally:

- View the public repository
- Review the documentation
- Evaluate the public demo
- Run permitted non-commercial tests
- Inspect the source for technical evaluation

Always refer to [`LICENSE`](LICENSE) for the actual terms.

## Commercial / production use

The current licence restricts production and commercial use and may require a separate commercial licence from the licensor.

Examples include:
